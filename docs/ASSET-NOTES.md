- **Firefly / Jinhsi**: copied, with the user's authorization, from their existing local CoSkin theme library. The MP4 and poster files were copied from the library's content-addressed assets, not recreated or edited. Their original artwork provenance has not been independently verified. They are presented as user-supplied unofficial demo media.
- Only these selected assets are included. The user's library index, other themes, credentials and machine paths are not distributed.

The site demo renders this project's real skin engine on a clearly labelled sample conversation UI. It is not a capture of the official Claude service. `manager-preview.png` is exported by the real Windows manager and shows its poster preview, not an actual Claude Desktop capture.
